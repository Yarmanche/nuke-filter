# Boxed Filter

Grayscale + colored-box-logo media filter, Supreme-style. Point it at photos,
videos, GIFs or a Telegram bot and it stamps your brand box on top.

Three front-ends share the same core:

| File | What it does |
|---|---|
| `run.py` | Photo batch filter, headless GIMP (`gimp -i`) |
| `nuke_vid.py` | Video / GIF / single-photo filter via ffmpeg |
| `nuke_server.py` | Local web server: serves `generator.html`, drag & drop in the browser (`http://localhost:8788`) |
| `nuke_bot.py` | Telegram long-poll bot: send media, get the filtered version back |
| `nuke_tray.py` | Tray icon that starts server + bot together (optional) |

## Setup

System requirements (install with your package manager — not pip):
- `ffmpeg` + `ffprobe` (video/GIF/photo filtering)
- `gimp` 3.x, optional — only for `run.py`

Python deps:

    python3 -m venv .venv && source .venv/bin/activate   # optional but recommended
    pip install -r requirements.txt

Configure by copying the example env file and editing it:

    cp .env.example .env

Everything is configurable via environment variables (or `.env`); nothing in the
code is machine-specific. All paths are relative to the project folder.

## Configuration (env vars / `.env`)

| Variable | Default | Used by |
|---|---|---|
| `FILTER_BOT_TOKEN` | — (required for the bot) | bot, tray |
| `FILTER_TEXT` | `YOUR BRAND` | `run.py` logo rendering |
| `FILTER_COLOR` | `196,30,30` | `run.py` box color (R,G,B) |
| `FILTER_APP_NAME` | `Boxed Filter` | bot `/start`, tray tooltip |
| `FILTER_LOGO_WIDTH` | `0.55` | default logo width fraction |
| `FILTER_PORT` | `8788` | server / tray |
| `FILTER_FONT` | auto-detect | path to a bold `.ttf` |
| `FILTER_LOGO` | `assets/nuke_logo.png` | logo image override |
| `FILTER_OUT_DIR` | `out/` | `run.py` output dir |

Note: `NUKE_BOT_TOKEN` is accepted as a legacy alias for `FILTER_BOT_TOKEN`.

## Usage

Photos (GIMP, batch):

    python3 run.py photo.jpg                 # one file -> out/photo.jpg
    python3 run.py ~/Pictures/               # whole folder
    python3 run.py *.jpg                     # glob
    python3 run.py in.jpg --text "ACME" --color 30,90,200
    python3 run.py in.jpg --grain            # subtle 90s film grain

Video / GIF / single photo (ffmpeg):

    python3 nuke_vid.py video.mp4 --pos center
    python3 nuke_vid.py clip.gif --pos br
    python3 nuke_vid.py video.mp4 --pos custom --fx 0.5 --fy 0.8
    python3 nuke_vid.py video.mp4 --width 0.4 --out out.mp4

Web UI:

    python3 nuke_server.py                   # open http://localhost:8788

Telegram bot (get a token from @BotFather first):

    FILTER_BOT_TOKEN=123:abc python3 nuke_bot.py
    # or put FILTER_BOT_TOKEN=... in a .env file next to the scripts

Tray (optional, needs `pystray`):

    python3 nuke_tray.py

## Quality notes (locked settings, do not tune down)

- GIF: two-pass palette (`palettegen`/`paletteuse`) with bayer dither; native
  fps and resolution preserved, max width 720.
- Video: libx264 crf 23, preset medium, `+faststart`, AAC 128k audio.
- Photos (`run.py`): desaturated inside GIMP, logo rendered crisp by Pillow and
  flattened on top so the color survives.

## Files

- `config.py` — shared config; every tunable is an env var with a sane default
- `scripts/nuke-filter.scm` — the GIMP Script-Fu filter (loaded from this folder)
- `assets/nuke_logo.png` / `.svg` — the box logo (regenerated by `run.py` when you change `--text`/`--color`)
- `out/` — default output folder (created on demand)
